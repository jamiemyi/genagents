# Survey agents

This population starts empty. Create an agent from your own answered survey
using [`build_survey_agent.py`](../../../build_survey_agent.py). Each generated
agent gets its own folder here with `survey_responses.json`, a profile, a
questionnaire, and memory files. See the [repo README](../../../README.md) for
the input format and commands. Generated folders contain the original answers;
review them before adding them to Git.
